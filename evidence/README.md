# Evidence

Each compatibility case should use a dedicated directory such as `A-direct-kill/`.

Preferred contents when legally/privacy safe to redistribute:

- `README.md` — scenario, PWCG version/commit, analyser version, schema, expected result.
- source log or a minimal/redacted reproduction input.
- analyser `result.json`.
- relevant PWCG AAR facts or redacted snapshot.
- `expected.md` / `actual.md` for a discrepancy.

Never publish personal credentials, unrelated FlightLogs, private campaign data, API keys or material that cannot be redistributed. If the raw log cannot be public, preserve a hash/version and a redacted factual report instead.
